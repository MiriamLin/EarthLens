# EarthLens

Explore NASA climate data for any location on Earth.

**Live:** https://earth-lens-two.vercel.app

## Features

- **Browse Data** — Search and filter 131 NASA POWER variables and 27 analysis functions, each with its units and description.
- **Time Series** — Build formulas with autocomplete or drag-and-drop blocks, measure anomalies against a custom baseline, and view linear trends with significance. Export as PNG or CSV.
- **Compare** — Overlay variables and locations on a single chart, with per-series trends and pairwise correlation.
- **Sound** — Turn data into melodies with a choice of instruments, and layer them as tracks.

## Data Source

Daily and monthly data from 1981 onward come from the [NASA POWER](https://power.larc.nasa.gov) API, based on MERRA-2 reanalysis and CERES SYN1deg satellite products. Data courtesy of the NASA Langley Research Center POWER Project, funded through the NASA Earth Science/Applied Science Program.
