# EarthLens

Explore NASA climate data for any place on Earth. Built for the 2026 NASA Space Apps Challenge.

## Features

- Browse 131 NASA POWER variables and 27 formula functions
- Time Series: write formulas with autocomplete or drag-and-drop blocks, see the trend, export PNG / CSV
- Anomalies against any baseline, e.g. `ts_anomaly(T2M, 1991, 2020)`
- Compare: overlay variables and locations, with correlation
- Sound: turn data into melodies and layer them as tracks
- Daily or monthly data from 1981 to today

## Data source

[NASA POWER](https://power.larc.nasa.gov) (MERRA-2 and CERES SYN1deg).
These data were obtained from the NASA Langley Research Center (LaRC) POWER Project funded through the NASA Earth Science/Applied Science Program.
